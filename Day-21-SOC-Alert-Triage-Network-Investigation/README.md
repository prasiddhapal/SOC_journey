# Day 21 - SOC Alert Triage & Investigation

## Objective

Practice SOC alert triage, process investigation, network correlation, and AI-assisted investigation.

## Practical Lab

**Platform:** TryHackMe - SOC L1 Alert Triage

## Topics Covered

- Alert prioritisation
- True Positive vs False Positive
- Process and endpoint investigation
- PID / PPID analysis
- PowerShell investigation
- Network correlation
- DNS, IP and proxy analysis
- IOC identification
- AI-assisted SOC investigation

## Key Lesson

**Alert severity tells you what to investigate first.  
Evidence determines what actually happened.**

## AI SOC Principle

> AI can accelerate investigation, but the analyst must validate AI-generated conclusions against real telemetry.
