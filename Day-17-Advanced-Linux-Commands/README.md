# 🛡️ Day 17 – Advanced Linux Commands for SOC Analysts

## 📌 Overview

Day 17 focused on advanced Linux commands used in Security Operations Centers (SOCs) for log analysis, text processing, evidence preservation, and efficient investigation workflows.

Rather than learning commands in isolation, each topic was practiced in a security investigation context with practical labs and interview preparation.

---

## 📚 Topics Covered

- journalctl
- awk
- sed
- tr
- tee
- xargs

---

## 🎯 Learning Objectives

- Analyze system logs using `journalctl`
- Extract structured information with `awk`
- Modify text streams using `sed`
- Translate and clean data using `tr`
- Preserve investigation evidence with `tee`
- Process multiple files efficiently using `xargs`

---

## 🛡️ SOC Applications

These commands are commonly used to:

- Investigate authentication failures
- Analyze Linux logs
- Preserve forensic evidence
- Process multiple log files
- Validate AI-generated investigation results
- Improve incident response workflows
